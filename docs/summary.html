C-MAP CHI Magnetic Analysis Program — QUEST トカマク 磁気面再構成

Python 3.10+ Numba JIT + prange NumPy / SciPy Taylor 緩和仮定 (λ = const.) refactor/high-performance ブランチ

概要

C-MAP は QUEST トカマクの CHI (Coaxial Helicity Injection) プラズマを対象とした磁気面再構成プログラムです。 Taylor 緩和後の状態 (λ = const.) を仮定し、ピックアップコイル計測 Bz から ポロイダル磁束分布・ポロイダル電流分布・Z-Bz プロファイルを再構成します。

仮定条件の詳細は T. Motoki, Master thesis (2024) を参照。

入出力

入力

TF / PF コイル電流、入射 (Gun) 電流、トロイダル電流、ピックアップコイル Bz

出力

2D ポロイダル磁束コンタ、2D ポロイダル電流分布、Z-Bz プロファイル比較

test30_#<count>/data/ (CSV) と img/ (PNG)

主要モジュール

main.py

109 行に圧縮されたオーケストレータ。ショット番号・解析時刻配列を編集して実行。

EquilibriumSolver

収束ループ本体 (415 行)。磁力線追跡 → λ 推定 → A_phi 再計算を反復。

GreenFunction

3.4 GB のグリーン関数行列 A_0 を起動時にロードし einsum で集約。

field_line_tracer

Numba JIT + prange による並列磁力線追跡。コア計算ホットスポット。

prepare_time_step

真空場計算・Bz フィッティング・ikr0/ikz0/elf0 設定。

TokamakConfig

QUEST 装置形状・PF/TF コイル配置・コイル電流時系列を保持。

処理ステップ (main.py 視点)

  1. cd_main() でカレントを main.py 位置に移動
  2. Grid / TokamakConfig 初期化
  3. get_CHI_Data(count) で ip / inj / G / bz_puc 取得
  4. 入射電流ピーク・減衰時刻 (t_inj_0 / t_decay) 抽出
  5. GreenFunction ロード (mfile_py.bin)
  6. 時刻ループ
    • prepare_time_step() で真空場・フィット・ikr0/ikz0 設定
    • EquilibriumSolver.solve_time_step() で λ 収束ループ
    • plot_magnetic_field / plot_psi / plot_bz_profile で可視化
  7. m_in.csv 出力 + 経過時間表示
